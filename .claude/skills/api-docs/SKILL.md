# API 文档引用

## 概述

此 skill 提供 km-design 项目的 API 接口文档查询和引用功能，帮助开发者在调用接口时快速查找相关文档。

## API 文档地址

- **完整文档**: <https://s.apifox.cn/b11b8e3b-536c-4b7b-8996-b5b802c81c7f/llms.txt?pwd=dg7O5Uik>

## 使用场景

1. **编写 API 调用代码时**: 查询接口的请求方法、路径、参数和返回值
2. **调试接口问题时**: 查看接口定义和预期行为
3. **新增功能时**: 了解可用的 API 接口
4. **代码审查时**: 验证接口调用的正确性

## 使用方法

在需要调用接口时，可以：

1. 直接访问对应的 API 文档链接
2. 根据模块分类快速定位相关接口
3. 查看接口的详细定义，包括请求参数、响应格式等

## 注意事项

- 所有接口的 base URL 为 `/api`
- 需要认证的接口需要在请求头中携带 `Authorization` token
- 部分接口需要特定的权限才能访问
